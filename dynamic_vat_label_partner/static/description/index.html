Dynamic VAT Label for Partners

This module dynamically updates the VAT field label and placeholder in the partner form based on the person type.

✨ Features

  • ✔ Dynamic VAT label based on partner type
  • ✔ Real-time UI update (no reload needed)
  • ✔ Clean OWL implementation
  • ✔ No backend overrides
  • ✔ Fully compatible with Odoo 17 / 18 / 19

🧠 Behavior

Person Type Label Placeholder
Company Tax ID Registration Number / VAT Number
Individual National ID National ID
Foreign Passport ID Passport ID

⚙️ Technical Details

  • Uses OWL patching on FormRenderer
  • Scoped only to res.partner
  • Does not affect performance or backend logic

🚀 Installation

  1. Install the module
  2. Open Contacts
  3. Change Person Type
  4. See VAT label update instantly
