Smart Tax ID Labels for Odoo

Automatically display the correct ID field (VAT, National ID, Passport) based on partner type — no confusion, no mistakes.

🚨 The Problem

Odoo uses a single "VAT" field for all partners, which can be confusing when dealing with companies, individuals, or foreign contacts. This often leads to incorrect data entry and user mistakes.

✅ The Solution

This module dynamically updates the VAT field label and placeholder based on the partner type, ensuring users always know what information to enter.

✨ Key Features

  • Automatic label switching based on partner type
  • Supports Company, Individual, and Foreign contacts
  • Real-time UI update (no page reload required)
  • Clean and lightweight OWL implementation
  • No backend changes — safe and fast

⚙️ How It Works

Partner Type Displayed Label Placeholder
Company Tax ID VAT / Registration Number
Individual National ID National ID
Foreign Passport ID Passport ID

🚀 Usage

  1. Install the module
  2. Go to Contacts
  3. Create or edit a partner
  4. Change the partner type
  5. Watch the VAT field update instantly
